# Historical replay — 2026-08-09

Dataset: `var/backtest/okx-90d.json`, recorded from OKX public history on
2026-08-09. It contains 90 study days plus warm-up candles, 88 instruments that
passed the recording-time E1 filter, and historical funding points where OKX
returned them.

The replay uses the live E1 → E2 → E3 → E4 → E5 functions. It only exposes
closed bars, fills a signal on a later bar, checks an existing stop before a
same-bar favourable trigger, and charges the recorded funding history. The
historical spread is the current observed spread stored in the dataset because
OKX candle history has no order-book snapshots.

## Result after the E2 gate correction

| Metric | Result | Policy target |
| --- | ---: | ---: |
| Equity | 320.00 → 298.77 USDT (-6.64%) | positive |
| Closed trades / entries | 8 / 8 | — |
| Trades per day | 0.09 | ~2 |
| Win rate | 37.50% (3W / 5L) | ~30% |
| Realised payoff ratio | 0.25:1 | ≥3:1; <2.5 is a fail |
| Maximum drawdown | 8.23% | governor sanity check |
| Time-stop hit rate | 37.50% | investigate |
| Fees / funding | 0.4080 / 0.2481 USDT | included |
| Observed leverage | 0.77x maximum | emergent |
| E1 universe | 9 / 16.5 / 25 min / average / max | breadth check |
| Favourable E2 cycles | 302 / 2161 | — |

The first replay used `minInstrumentsPassingRegime: 3`. That was structurally
too high: the reachable universe averaged 16.5 instruments and E3 usually
produced only one long and one short extreme. E2 therefore stood down even when
both available extremes passed. The policy is now set to 2, the maximum that
the normal E3 tail can actually provide.

The corrected policy trades more, but its full-period payoff is still poor. The
30% win-rate neighbourhood is not the problem; the winners still do not pay for
the losers.

On the same unseen 45-day windows, the corrected fixed policy produced 32 trades
and +21.96 USDT with 6.47% worst-fold drawdown. A broader entry relaxation made
more trades but increased drawdown without improving unseen return.

The exit-late variant was only marginally better on the unseen windows (+22.92
USDT versus +21.96) and did not improve the full-period result. It is not enough
evidence to change the exit ladder before competition start; the E2 correction
is the change supported by the data.

Run it again with:

```bash
npm run backtest -- var/backtest/okx-90d.json
```
